# 📚 자동차 경주

## 📖 기능 요구사항
주어진 횟수 동안 여러 대의 자동차가 전진 또는 멈추는 단순한 자동차 경주 게임을 구현 한다. <br>
사용자는 자동차 이름과 시도 횟수를 입력하며, 매 라운드마다 자동차의 이동 상태를 출력하고, <br>
모든 시도가 끝난 뒤 최종 우승자를 알려준다.

## 🎮 기본 동작
- 사용자는 경주할 자동차 이름을 쉼표 (`,`) 기준으로 입력한다.
    - 예: `pobi,woni,jun`
- 각 자동차 이름은 **1자 이상 5자 이하**만 가능하다.
- 사용자는 **시도할 횟수**를 입력한다.
- 각 자동차는 0~9 사이의 무작위 수를 구해 **4 이상일 경우 전진**한다.
- 각 차수별 실행 결과를 출력한다.
- 경주가 모두 끝나면 최종 우승자를 출력한다.
    - 우승자가 여러 명일 경우 쉼표(`,`)로 구문한다.

## ⚠️ 예외 처리
- 자동차 이름이 5자 초과이거나 비어있는경우 -> `IllegalArgumentException`
- 시도 횟수가 0 이하이거나 숫자가 아닌 경우 -> `IllegalArhumentException`
- 예외 발생 시 프로그램은 종료되어야 한다.

## 🧩 사용 라이브러리
- `camp.nextstep.edu.missionutils.Console` : 사용자 입력 처리
- `camp.nextstep.edu.missionutils.Randoms` : 난수 생성

## 🧠 프로그래밍 요구사항 반영 내역
- JDK 21에서 실행 가능
- `System.exit()` 호출 금지
- 들여쓰기(Indent) depth 2 이하 유지
- 3항 연산자 사용 금지
- 메서드는 한 가지 역할만 수행
- 예외 발생 시 `IllegalArgumentException` 사용

## 💻 입출력 요구 사항
### 입력
- 경주할 자동차 이름(이름은 쉼표(`,`) 기준으로 구분)
```java
    pobi,woni,jun
```
- 시도할 횟수
```java
    5
```

### 출력
- 차수별 실행 결과
```java
    pobi : --
    woni : ----
    jun : ---
```
- 단독 우승자 안내 문구
```java
    최종 우승자 : pobi
```
- 공동 우승자 안내 문구
```java
    최종 우승자 : pobi, jun
```

### 실행 결과 예시

```java
    경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
    pobi,woni,jun
    시도할 횟수는 몇 회인가요?
    5
    
    실행 결과
    pobi : -
    woni :
    jun : -
    
    pobi : --
    woni : -
    jun : --
    
    pobi : ---
    woni : --
    jun : ---
    
    pobi : ----
    woni : ---
    jun : ----
    
    pobi : -----
    woni : ----
    jun : -----
    
    최종 우승자 : pobi, jun
```
